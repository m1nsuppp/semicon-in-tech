# 프로세서 반도체

가장 중요하고 많이 사용되는 반도체로, 하드웨어와 소프트웨어를 연결하는 역할을 수행한다.
- 하드웨어: 연산 및 계산을 수행하는 실체적 장치(연산기)로, 반도체 제조 공정을 통해 물리적으로 만들어진다.
- 소프트웨어: 주어진 하드웨어를 여러 단계에 걸쳐서 사용함으로써 하드웨어를 효율적으로 활용할 수 있도록 하는 것

프로세서(CPU, GPU, AP 등)는 시스템의 **뇌** 역할을 하는 System LSI(시스템 반도체)의 핵심이다. 데이터 저장용인 메모리 반도체와 달리 전체 시스템을 제어하고 연산을 총괄하므로 가장 중추적인 역할을 수행
- LSI: Large Scale Integration

## 하드웨어와 소프트웨어를 연결

프로세서 내부에는 ISA(Instruction Set Architecture, 명령 집합 구조)라는 규격이 존재한다. 이는 소프트웨어(코드)를 하드웨어가 이해할 수 있는 전기적 신호(0과 1)로 변환해 연산기에 전달하는 인터페이스 역할을 한다.
> ISA는 소프트웨어 개발자와 하드웨어 설계자 간의 약속(Interface/Contract)이다. x86(Intel/AMD), ARM, RISC-V 등이 대표적인 ISA의 종류

- 추상적 개념의 물리적 구현: 알고리즘은 문제를 해결하기 위한 **논리적 절차나 순서**이다. 하드웨어인 반도체는 스스로 논리를 생각하지 못하고 전기 신호(0과 1)만 인식하므로, 알고리즘을 하드웨어가 실행 가능한 형태(기계어 및 명령어)로 번역해 담아낸 것이 바로 프로그램이다.

- ISA를 통한 중계: 프로그래밍 언어로 작성된 알고리즘을 컴파일러가 변환하여, 하드웨어(프로세서)가 미리 약속된 규칙에 따라 이해할 수 있는 규격으로 다듬은 결과물이 **프로그램**

- 하드웨어 제어의 실체: 알고리즘이 "A와 B를 더하고 C를 곱하라"는 아이디어라면, 프로그램은 하드웨어 내부의 스위치(트랜지스터)들을 정해진 순서대로 켜고 끄도록 지시하는 전기적 실행 계획서

결론적으로, "알고리즘(아이디어/논리) -> 프로그램(하드웨어용 표현/번역) -> 하드웨어(물리적 실행)"로 이어지는 흐름

## 프로세서 반도체와 컴퓨터 구조의 맥락에서 프로그램(Program)과 소프트웨어(Software)의 차이

| 구분    | 프로그램(Program)             | 소프트웨어(Software)                  |
| ----- | -------------------------- | --------------------------------- |
| 핵심 정의 | 하드웨어가 실행할 명령어들의 구체적 집합체    | 프로그램과 이를 구동 및 관리하는 시스템 전체 생태계       |
| 관점    | 하드웨어/반도체 중심(실행 단위)        | 사용자/시스템 중심(기능 및 환경)              |
| 비유    | 건축물의 "설계도면 한 장" 또는 "악보 하나" | 건물 전체의 "설계 및 관리 시스템" 또는 "교향악단 전체"   |
| 구성 요소 | 코드, 기계어 명령어, 실행 파일(.exe 등) | 여러 프로그램 + 라이브러리 + 데이터 + 문서 + 운영체제 |

#### 1. 프로그램(Program): 하드웨어에 내려지는 단일 명령어 실행서

- 개념: 알고리즘을 하드웨어가 이해할 수 있는 언어로 바꿔놓은 **명령어(Instruction)의 시퀀스(순서)**.
- 맥락상 의미: 프로세서 반도체의 연산기(ALU)가 메모리에서 순차적으로 가져와(Fetch) 해석하고(Decode) 실행(Execute)하는 **구체적이고 실체적인 단위**를 뜻한다.
- 예시: 1부터 10까지 더하는 정렬 알고리즘 코드 파일, 특정 연산을 수행하는 1개의 실행 파일

#### 2. 소프트웨어(Software): 하드웨어를 효율적으로 쓰기 위한 거대한 체계

- 개념: 단순한 코드의 집합을 넘어, 하드웨어 자원을 제어하고 프로그램을 실행할 수 있는 **환경 전체**를 의미한다.
- 맥락상 의미: **주어진 하드웨어를 여러 단계에 걸쳐 효율적으로 활용하도록 하는 것**이 바로 소프트웨어의 개념. 여러 프로그램이 하드웨어 자원(CPU, 메모리)을 다투지 않고 효율적으로 나누어 쓰도록 관리하는 **운영체제(OS), 드라이버, 컴파일러 등을 모두 포함하는 포괄적 개념**
- 예시: Windows / Linux (운영체제), 웹 브라우저 패키지, AI 개발 프레임워크(PyTorch 등)

#### 요약

알고리즘을 하드웨어가 이해하도록 표현한 것은 프로그램에 가장 가깝고, 이 프로그램들이 반도체 하드웨어 위에서 유기적이고 효율적으로 돌아가도록 판을 깔아주는 상위의 개념이 소프트웨어
