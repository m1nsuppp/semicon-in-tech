# Intel vs ARM 프로세서 비교

ISA는 소프트웨어 개발과 하드웨어 개발이 독립적으로 이루어질 수 있도록 하는 약속으로, Intel의 ISA 기반 생태계와 ARM의 ISA를 기반 생태계로 나뉜다.

- Intel ISA: PC 및 서버용 컴퓨터
- ARM ISA: 스마트폰/태블릿 컴퓨터

## Intel의 x86 ISA

CISC(Complex Instruction Set Computer)아키텍처라고 부르며, 매우 복잡한 ISA들이 많이 포함됨
- 복잡하고 다양한 명령어를 처리하도록 설계되어 고성능 작업(게이밍, 전문 영상 편집, 서버)에 강함
- 복잡한 ISA들 때문에 하드웨어 설계가 어려움
  - 트랜지터 개수도 많이 필요하고, 동작 clock을 높이기 어렵고, 높은 전력이 소모됨
- Intel ISA가 시장을 장악해서 PC용 Software가 대부분 Intel ISA에 맞게 개발 되어서, 새로운 ISA 채택이 어려움

## ARM의 ISA

스마트폰용 AP 개발을 위해 저전력이 핵심 요소로 떠오르면서 ARM의 ISA가 채택됨. RISC(Reduced Instruction Set Computer) 아키텍처라고 부르며, 비교적 단순한 ISA들로만 구성됨

- PC와 달리 스마트폰은 소프트웨어를 처음부터 새로 개발해야 했기에, 기존 Intel ISA 호환성에서 벗어나 새로운 ARM ISA를 도입할 수 있었음
- 복잡한 하드웨어(예: 곱셈기)를 줄이고 덧셈 반복 등으로 연산을 처리하여, 하드웨어 복잡도를 낮추고 트랜지스터 개수를 줄였음
- 단순한 명령어 중심 설계 덕분에 동작 속도를 올리고 전력 소모를 크게 줄일 수 있음(단, 최근 고성능 RISC 프로세서는 성능 향상을 위해 곱셈기 등도 다시 포함하는 추세)
- 기존에는 모바일 기기 중심으로 쓰이던 ARM ISA가 최근에는 노트북, 서버 등 고성능 영역으로 영역을 확장하며 적용 시도가 활발히 이루어지고 있음(e.g. Apple M시리즈)
